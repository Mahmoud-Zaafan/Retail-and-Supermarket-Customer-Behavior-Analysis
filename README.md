# Retail-and-Supermarket-Customer-Behavior-Analysis

The goal of this project is to identify meaningful customer segments and classify customers based on their spending patterns. Retailers often have massive transactional data but struggle to extract actionable insights efficiently.

## Project Overview
This repository contains Jupyter notebooks and CSV datasets used to analyse customer behaviour in a retail and supermarket setting.

### Project Structure

```
notebooks/   - Jupyter notebooks for preprocessing and modelling
data/
  raw/       - the original dataset
  processed/ - cleaned datasets generated by the notebooks
```

## Dataset
Download `customer_supermarket.csv` (TSV format) it at `data/raw/customer_supermarket.csv`. Running the preprocessing notebook will read this raw file and generate the processed datasets `categorical_customer_data.csv` and `numerical_customer_data.csv` inside `data/processed/`.

The primary dataset stored in `categorical_customer_data.csv` has the following columns:

| Column       | Type    | Description                                |
|--------------|---------|--------------------------------------------|
| `CustomerID` | integer | Unique identifier for a customer           |
| `Country`    | string  | Customer's country                         |
| `Fav_Weekday`| string  | Day of the week with the most purchases    |
| `Fav_Month`  | string  | Month with the highest purchasing activity |

`categorical_customer_data.csv` is produced by executing the **Data Preprocessing** notebook. The repository also contains `numerical_customer_data.csv` with derived numerical features for modelling.

## Setup
Install the required Python packages in a virtual environment:

```bash
pip install pandas numpy scikit-learn jupyter
```

## Running the Notebooks
Launch Jupyter and run the notebooks in order:

```bash
jupyter notebook
```

1. Open `notebooks/Data Preprocessing.ipynb` and run all cells. The notebook reads `data/raw/customer_supermarket.csv` and saves the processed files `categorical_customer_data.csv` and `numerical_customer_data.csv` to `data/processed/`.
2. Next, open `notebooks/Modelling.ipynb` to explore different machine learning models using the processed data from `data/processed/`.
