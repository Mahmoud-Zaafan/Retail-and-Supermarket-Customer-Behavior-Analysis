# Notebooks

This folder contains the Jupyter notebooks used for preprocessing the raw dataset and building simple models.

- **Data Preprocessing.ipynb** – reads the raw data from `data/raw/customer_supermarket.csv` and produces the cleaned CSV files under `data/processed/`.
- **Modelling.ipynb** – demonstrates exploratory modelling using the processed data.

Run these notebooks in the order listed above after installing the project dependencies.
